# Prompt: Single Voice Note

Turn the following voice-note transcript into an Obsidian Markdown note.

Requirements:

1. Generate a short title.
2. Extract 1-5 topics.
3. Write a concise summary.
4. Extract action items.
5. Extract people.
6. Suggest suitable topic-note links.
7. Preserve the raw transcript.
8. Do not over-explain.

Output format:

```markdown
---
date:
source: voice
topics: []
people: []
title:
---

# Title

## Summary

## Topics

## Action Items

## People

## Links

## Raw Transcript
```
