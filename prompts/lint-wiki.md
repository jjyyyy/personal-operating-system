# Prompt: Lint Wiki

Health-check this voice-notes wiki.

Read first:

1. `index.md`
2. `AGENTS.md`
3. `catalog.md` if broad discovery is needed
4. `log.md` for recent operations

Look for:

1. Contradictions between topic notes and newer daily notes.
2. Stale claims that newer notes have superseded.
3. Missing cross-references between related topic notes.
4. Important repeated concepts that lack topic notes.
5. Topic notes with no source-note links.
6. Daily notes that should be promoted into durable topic memory.
7. Action items that are vague, stale, duplicated, or not executable.

Output:

```markdown
# Wiki Lint: YYYY-MM-DD

## High Priority

## Missing Or Weak Links

## Promotion Candidates

## Stale Or Conflicting Claims

## Action Item Cleanup

## Suggested Edits
```
