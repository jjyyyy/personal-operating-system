# Prompt: Topic Update

Update the target topic note using the provided daily notes or weekly review.

Rules:

1. Do not rewrite the whole topic note unless the structure is clearly broken.
2. Preserve existing judgments.
3. Add or adjust only content with long-term value.
4. New content must link back to source notes.
5. Separate facts, patterns, decisions, open questions, and next actions.
6. If evidence is insufficient, list suggested changes first instead of inventing content.

Output:

```markdown
## Suggested Changes

## Patch Draft

## Source Notes Used
```
