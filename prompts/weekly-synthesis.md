# Prompt: Weekly Synthesis

Read all `daily/` voice notes for the week and create one weekly review.

Focus:

1. Group by topic.
2. Find repeated themes.
3. Extract concrete action items.
4. Mark unfinished or follow-up items.
5. Identify content worth promoting into `topics/`.
6. Suggest specific updates for each relevant topic note.

Output structure:

```markdown
# Weekly Review: YYYY-MM-DD to YYYY-MM-DD

## Top Themes

## Repeated Topics

## Action Items

## People

## Topic Note Updates

## Open Questions

## Next Week Focus
```
